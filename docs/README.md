# Memory Matching Game

A browser-based memory card matching game built with HTML, CSS, and JavaScript. Flip cards, memorize patterns, and test your memory.

---

## Features

* Interactive card flipping system
* Match detection logic
* Win condition tracking
* Responsive grid layout
* Simple and clean UI
* Restartable gameplay

---

## Technologies Used

* HTML5
* CSS3
* JavaScript (DOM Manipulation & Event Handling)

---

## How to Play

1. Click on a card to flip it.
2. Match the pattern shown.
3. If the pattern is wrong match, you lose a life.
4. You get three livees.
5. Keep matching the pattern to move through levels.


```bash
cd memory-matching-game
```

3. Launch `index.html` in your browser.
